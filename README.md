Bank Account Management System

A Java banking application developed as a team project for a Java programming course.

Overview

This program simulates basic banking operations using object-oriented programming. It creates different types of bank accounts and allows users to manage balances through deposits, withdrawals, transfers, and interest calculations.

Features

Create checking and savings accounts

Automatically assign account numbers

Display account information

Deposit funds

Withdraw funds

Transfer money between accounts

Calculate interest for savings accounts

Track account balances

Handle insufficient-funds errors using exceptions

Technologies and Concepts

Java

Object-oriented programming

Classes and objects

Encapsulation

Private instance variables

Constructors

Getters and setters

Static variables

Static methods

Exception handling

Basic financial calculations

Project Structure

BankAccount.java - Defines account data and banking operations

BankAcountDemo.java - Demonstrates the banking operations

Financial.java - Provides a static method for calculating percentages
